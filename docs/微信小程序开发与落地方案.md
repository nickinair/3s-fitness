## 二、 五步落地执行手册（方案 A：WebView 混合架构）

### Step 1：对齐小程序工程配置，在微信开发者工具跑通（已完成 ✅）
1. 根目录 `project.config.json` 已添加 `"miniprogramRoot": "miniprogram/"`，无论在微信开发者工具中打开项目根目录 `/Users/nickni/Desktop/fitness-app` 还是子目录 `/Users/nickni/Desktop/fitness-app/miniprogram` 均可正常编译。
2. `project.config.json` 与 `project.private.config.json` 已默认设置 `"urlCheck": false`，本地模拟器可直接加载 `https://3s-fitness.cn/m/`。
3. `miniprogram/pages/index/index.js` 已支持小程序参数直达（如 `?path=checkin` 直达签到页）以及右上角「转发给朋友 / 分享到朋友圈」。

### Step 2：配置微信公众平台「业务域名」与「服务器域名」（当前步骤 👉）
要让手机微信真机（不开启调试模式）及正式版正常打开 `<web-view>`，需在微信后台完成域名白名单配置：

1. 打开并登录 [微信公众平台 (mp.weixin.qq.com)](https://mp.weixin.qq.com/)。
2. 进入左侧菜单 **「开发与服务 → 开发管理 → 开发设置」**。
3. **配置服务器域名**：
   - `request 合法域名`：`https://3s-fitness.cn`
   - `uploadFile 合法域名`：`https://3s-fitness.cn`
   - `downloadFile 合法域名`：`https://3s-fitness.cn`
4. **配置业务域名（核心必配）**：
   - 在「业务域名」板块点击「开始配置 / 修改」。
   - 点击 **「下载校验文件」**（文件名形如 `MP_verify_xxxxxxxxxxxx.txt`）。
   - 将该 `.txt` 文件放入项目的 `server/web/portal/` 目录下（或直接把文件名和内容发给 AI 助手代放并一键部署到服务器）。
   - 部署后确认 `https://3s-fitness.cn/MP_verify_xxxxxxxxxxxx.txt` 可访问，在微信后台填入 `3s-fitness.cn` 并点击保存。

### Step 3：微信原生能力增强（可选迭代）
1. **微信手机号一键快捷登录**：
   - 在微信后台「开发设置」获取 **AppSecret（小程序密钥）**，填入服务端 `server/secrets.json`。
   - 新增小程序原生授权页调用 `<button open-type="getPhoneNumber">`，后端换取手机号后自动匹配/绑定 `biz_vip_user` 会员档案并下发 JWT Token 免密进入 H5。
2. **门店签到小程序码**：
   - 正式上线或体验版生成带参路径 `pages/index/index?path=checkin` 的小程序码，张贴在门店前台，会员微信扫码即入场签到。

### Step 4：小程序后台隐私指引与提审准备
1. **服务类目**：建议添加 **「体育 → 体育场馆服务」**。
2. **《用户隐私保护指引》**：在「设置 → 服务内容声明 → 用户隐私保护指引」中声明收集 **手机号**（用于会员登录与档案绑定）、**选中的照片或视频信息**（用于上传头像与蜕变相册）。
3. **提审测试账号**：
   - 会员测试账号：`13911110001` / 密码：`123456`
   - 员工测试账号：`manager01` / 密码：`admin123`

### Step 5：上传代码、体验版验证与提交审核
1. 在微信开发者工具点击右上角 **「上传」**（填写版本号 `1.0.0`）。
2. 在微信公众平台「管理 → 版本管理」中将其选为 **体验版**，手机扫码验收通过后点击 **「提交审核」**，审核通过后点击 **「发布」** 即可正式上线。
