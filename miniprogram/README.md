# 3S健身 小程序（WebView 壳）· 上线办理清单

小程序壳工程已就绪，加载现有移动端 H5（会员端+员工端），功能零重写、数据与后台实时一致。
您只需办好下面两件事，剩下的交给 Claude。

## 需要您办理的两件事

### ① 注册微信小程序（约 1~3 个工作日）
1. 打开 https://mp.weixin.qq.com → 立即注册 → 选「小程序」
2. 主体类型选 **企业**（个人主体不能用 web-view，必须企业主体！）
3. 需要：营业执照、法人微信扫码验证、对公账户小额打款验证（或法人人脸验证）
4. 认证费 30 元/年（微信认证）
5. 完成后在「开发管理 → 开发设置」拿到 **AppID**，发给 Claude

### ② 域名注册 + ICP 备案（备案约 1~2 周，最耗时，建议立刻启动）
1. 在腾讯云买个域名（如 3sfit.cn，几十元/年）：https://console.cloud.tencent.com/domain
2. 在腾讯云提交 **ICP 备案**（服务器就是腾讯云的 1.14.47.160，符合备案条件）：
   https://console.cloud.tencent.com/beian —— 需要营业执照、法人身份证、手机核验
3. 备案通过后把域名（或子域名如 gym.3sfit.cn）解析 A 记录到 **1.14.47.160**
4. 告诉 Claude 域名，Claude 会执行 `deploy/nginx-setup.sh` 配好 HTTPS

## 拿到 AppID + 域名后 Claude 来做的事
1. 服务器配 Nginx + 免费 SSL 证书（一条命令）
2. 改 `miniprogram/config.js` 的 H5_URL 为正式 https 域名
3. `project.config.json` 填入正式 AppID
4. 指导在小程序后台「开发设置 → 业务域名」添加域名（校验文件放到服务器）
5. 微信开发者工具导入本目录 → 预览真机验证 → 上传代码 → 提交审核

## 现在就能先体验（无需等待）
- 微信开发者工具（https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html）
  导入本目录，AppID 选「测试号」，把 config.js 的 H5_URL 临时改成 `http://1.14.47.160:8090/m/`，
  并在「详情 → 本地设置」勾选「不校验合法域名」，即可在模拟器里跑通全部功能
- 手机微信里直接发送链接 `http://1.14.47.160:8090/m/` 也可立即使用（H5 在微信内打开体验已接近小程序）

## 审核提示
- 小程序名称建议：「3S健身」或「3S健身助手」（需与营业执照经营范围沾边）
- 类目选择：体育 → 健身/运动（涉及会员卡在线售卖，可能需补充《高危险性体育项目经营许可》以外的常规健身类目即可）
- web-view 页面内不要出现诱导下载、支付绕过等内容，现有 H5 的「模拟微信支付」上线前需接入真实微信支付（届时告知 Claude 接入 JSAPI 支付）
